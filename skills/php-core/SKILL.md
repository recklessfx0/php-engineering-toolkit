# php-core

Identify the lowest supported PHP runtime from Composer constraints and the deployment matrix. Compare with the local CLI runtime before interpreting lint results. Preserve public signatures, named parameter names and exception behavior unless the change authorizes a contract update. Keep dependency wiring at existing composition boundaries. Read [compatibility and design](references/workflow.md) for version-sensitive decisions.
